# Suprathon Frontend

A modern, responsive frontend application built with React and Vite. This project features a beautiful, accessible interface with dark mode support, smooth animations, and mobile-first responsive design.

## 🚀 Features

- ⚡ **Lightning Fast** - Built with Vite for instant hot reload and optimized builds
- 📱 **Responsive Design** - Perfect on all devices with modern CSS Grid and Flexbox
- 🎨 **Modern UI** - Beautiful, accessible interface with smooth animations
- 🔧 **Developer Friendly** - Clean code structure with React best practices
- 🌙 **Dark Mode** - Toggle between light and dark themes seamlessly
- 🚀 **Production Ready** - Optimized for performance and SEO

## 🛠️ Tech Stack

- **React 19** - Latest version with modern features
- **Vite** - Fast build tool and development server
- **CSS3** - Modern styling with CSS Grid, Flexbox, and custom properties
- **ES6+** - Modern JavaScript features

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/cipher425/suprathon-Rituraj.git
cd suprathon-Rituraj
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🏗️ Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory, ready for deployment.

## 🎨 Design System

The project uses CSS custom properties for theming, making it easy to customize colors and maintain consistency:

- **Light Theme**: Clean, modern design with subtle shadows
- **Dark Theme**: Easy on the eyes with proper contrast ratios
- **Responsive**: Mobile-first approach with breakpoints at 480px, 768px, and 1024px

## 🚀 Deployment

The project is ready for deployment to any static hosting service:

- **Vercel**: Connect your GitHub repository for automatic deployments
- **Netlify**: Drag and drop the `dist` folder or connect via Git
- **GitHub Pages**: Use GitHub Actions to build and deploy
- **AWS S3**: Upload the `dist` folder contents to an S3 bucket
